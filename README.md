# Weather App

Приложение для просмотра погоды по координатам с картой и поддержкой нескольких виджетов.

## Возможности

- Ввод географических координат (широта/долгота)
- Отображение текущей погоды
- Встроенная карта местоположения
- Добавление нескольких виджетов
- Автосохранение виджетов
- Разные фоны в зависимости от погоды

## Отображаемые данные

- Температура (°C)
- Ощущаемая температура
- Погодные условия
- Влажность воздуха (%)
- Скорость ветра (м/с)
- Атмосферное давление (мм рт. ст.)
- Местное время
- Карта местоположения

## Технологии

- JavaScript (ES6+)
- HTML/CSS
- OpenWeatherMap API
- Яндекс.Карты API
